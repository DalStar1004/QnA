# 단어 블록 톡톡 🍭

이 폴더 하나로 게임이 전부 돌아갑니다. 설치도, 인터넷 연결도 필요하지 않습니다.

## 어떻게 하나요

### 혼자 하기

`word_connection_game.html` 을 더블클릭하면 끝입니다.

- **제시어 맞추기** — 블록을 이어 카테고리 단어를 만듭니다.
  (왼쪽 클릭으로 블록을 고르고, 오른쪽 클릭으로 고르기를 끝냅니다.)
- **AI 힌트 맞히기** — 힌트를 보고 낱말을 맞힙니다. (AI를 쓰려면 아래 *선택 사항* 참고)
- **산업재산권 문제** — `quiz-data/산업재산권_문제.txt` 에 적힌 문제를 처음부터 끝까지 냅니다.
  한 문제에 기본 **10초**, 시간이 지나면 정답을 알려줍니다.
  시간·블록 개수는 ⚙️ 설정에서 정하며 **모드 1의 설정과 별개**입니다.
  설정에서 문제 파일을 내려받아 문제를 덧붙인 뒤 다시 올리면 문제가 늘어납니다
  (자세한 방법은 [`quiz-data/README.md`](quiz-data/README.md)).
  (기본 문제 파일을 읽어야 해서 보통은 **서버 주소로 열었을 때** 씁니다. 게임 파일을 직접
  더블클릭한 경우에는 설정에서 문제 파일을 직접 올리면 그 문제로 진행할 수 있습니다.)

### 친구들과 함께 하기 (멀티플레이)

**`서버 켜기.bat`** 을 더블클릭합니다. 검은 창이 열리고 잠시 뒤 브라우저에 게임이 열립니다.

- 같은 인터넷에 있는 다른 PC는 그 창에 적힌 `http://192.168.x.x:3000` 주소로 들어옵니다.
- 그 주소로 들어가면 **시작 화면**이 먼저 뜹니다. 거기서 [접속하기] 를 누르면 멀티플레이(`/multi`)로 갑니다.
- 처음 켤 때 Windows 방화벽 창이 뜨면 **[액세스 허용]** 을 눌러야 다른 PC에서 들어올 수 있습니다.
- 자세한 설명은 [`server/README.md`](server/README.md) 를 보세요.

인터넷 서버(예: Vultr)에 올려서 **주소만 알려주고 같이 하는 방법**은
[`docs/03-배포/Vultr-배포-계획.md`](docs/03-배포/Vultr-배포-계획.md) 에 정리해 두었습니다.

## 이 폴더에 무엇이 들어 있나요

| 이름 | 무엇인지 |
|---|---|
| `word_connection_game.html` | 혼자 하기 게임. HTML·CSS·JS가 이 파일 하나에 다 들어 있습니다. |
| `서버 켜기.bat` | 멀티플레이 서버를 켜는 스크립트. 더블클릭만 하면 됩니다. |
| `server/` | 멀티플레이 서버(Express + Socket.IO)와 멀티플레이 화면. |
| `tools/node/` | 이 폴더 전용 Node.js. PC에 Node를 설치하지 않아도 서버가 돌아갑니다. |
| `assets/` | 게임 화면이 쓰는 그림과 글꼴. 아이콘·트로피·배경 미리보기·글꼴이 들어 있습니다. |
| `assets/backgrounds/` | 게임 배경 그림 `배경1~4.png`. |
| `source-images/` | 원본 그림(`아이콘.png`·`우승.png`·`챔피언 뱃지.png`). 여기서 잘라 낸 것이 `assets/` 에 있으므로, 게임 실행에는 쓰이지 않습니다. |
| `quiz-data/` | 모드 3이 내는 문제 파일. `산업재산권_문제.txt` 를 고치면 게임에 바로 반영됩니다. |
| `docs/` | 기획·설계 문서와 작업 기록. |

## 인터넷 없이도 되나요

**됩니다.** 게임을 굴리는 데 필요한 것은 전부 이 폴더 안에 있습니다.

- 글꼴(Fredoka·Jua)은 `assets/fonts/` 에 넣어 두고 파일에서 직접 불러옵니다.
  예전에는 구글 폰트를 인터넷에서 받아 썼는데, 그러면 인터넷이 없을 때 글꼴이 달라졌습니다.
- 서버가 쓰는 라이브러리는 `server/node_modules/` 에 이미 들어 있습니다.
- 서버를 켤 Node.js도 `tools/node/` 에 들어 있습니다.

### 선택 사항 — AI 힌트 맞히기의 문장 힌트

스무고개에서 `"바다에서 사는 생물"` 같은 **문장 힌트**를 받으려면 이 PC에
[Ollama](https://ollama.com) 가 켜져 있어야 합니다. 이것만은 폴더 안에 넣을 수 없습니다
(모델 파일이 수 GB라 게임과 함께 두기 어렵습니다).

**Ollama가 없어도 스무고개는 그대로 할 수 있습니다.** 그때는 문장 힌트 대신
글자 수·초성·첫 글자 힌트가 열리고, 화면이 그 사실을 알려 줍니다.

준비 방법은 게임 안에서도 볼 수 있습니다 — **[스무고개 시작] 화면의 `준비 방법` 버튼**.
연결은 [스무고개 시작]을 누를 때 알아서 맞춰지므로 따로 손댈 것이 없습니다.
스무고개 횟수를 바꾸거나, Ollama 주소·모델을 고치거나, 예열해 둔 모델을 램에서 내리려면
**⚙️ 게임 설정 › 🔁 스무고개 횟수 / ⚙️ qwen2.5:7b 연결** 을 씁니다.

## 개발자용 메모

- **저장소에도 실행 환경이 함께 들어 있습니다.** `tools/node/`(Node.js)와
  `server/node_modules/`(express·socket.io)를 `.gitignore` 에서 빼지 않았습니다.
  폴더를 복사하든 `git clone` 으로 받든, 아무것도 설치하지 않고 바로 실행할 수 있습니다.
  (그만큼 저장소가 커집니다 — 약 130MB, 그중 `node.exe` 하나가 89MB입니다.)
- `.gitattributes` 가 위 두 경로의 줄바꿈 변환을 막습니다.
  Windows 기본값(`core.autocrlf=true`)을 그대로 두면 받아 쓸 때 파일 내용이 바뀔 수 있습니다.
- 작업 기록은 `docs/작업기록/작업기록.md` 에 한 건씩 쌓입니다.
