# 단어 연결 게임 🍭

이 폴더 하나로 게임이 전부 돌아갑니다. 설치도, 인터넷 연결도 필요하지 않습니다.

## 어떻게 하나요

### 혼자 하기

`word_connection_game.html` 을 더블클릭하면 끝입니다.

- **제시어 맞추기** — 블록을 이어 카테고리 단어를 만듭니다.
- **AI 스무고개** — 힌트를 보고 낱말을 맞힙니다. (AI를 쓰려면 아래 *선택 사항* 참고)

### 친구들과 함께 하기 (멀티플레이)

**`서버 켜기.bat`** 을 더블클릭합니다. 검은 창이 열리고 잠시 뒤 브라우저에 게임이 열립니다.

- 같은 인터넷에 있는 다른 PC는 그 창에 적힌 `http://192.168.x.x:3000` 주소로 들어옵니다.
- 처음 켤 때 Windows 방화벽 창이 뜨면 **[액세스 허용]** 을 눌러야 다른 PC에서 들어올 수 있습니다.
- 자세한 설명은 [`server/README.md`](server/README.md) 를 보세요.

## 이 폴더에 무엇이 들어 있나요

| 이름 | 무엇인지 |
|---|---|
| `word_connection_game.html` | 혼자 하기 게임. HTML·CSS·JS가 이 파일 하나에 다 들어 있습니다. |
| `서버 켜기.bat` | 멀티플레이 서버를 켜는 스크립트. 더블클릭만 하면 됩니다. |
| `server/` | 멀티플레이 서버(Express + Socket.IO)와 멀티플레이 화면. |
| `tools/node/` | 이 폴더 전용 Node.js. PC에 Node를 설치하지 않아도 서버가 돌아갑니다. |
| `assets/` | 아이콘·트로피·배경 미리보기·글꼴. |
| `배경1~4.png`, `아이콘.png` 등 | 게임 화면에 쓰는 그림. |
| `docs/` | 기획·설계 문서와 작업 기록. |

## 인터넷 없이도 되나요

**됩니다.** 게임을 굴리는 데 필요한 것은 전부 이 폴더 안에 있습니다.

- 글꼴(Fredoka·Jua)은 `assets/fonts/` 에 넣어 두고 파일에서 직접 불러옵니다.
  예전에는 구글 폰트를 인터넷에서 받아 썼는데, 그러면 인터넷이 없을 때 글꼴이 달라졌습니다.
- 서버가 쓰는 라이브러리는 `server/node_modules/` 에 이미 들어 있습니다.
- 서버를 켤 Node.js도 `tools/node/` 에 들어 있습니다.

### 선택 사항 — AI 스무고개의 문장 힌트

스무고개에서 `"바다에서 사는 생물"` 같은 **문장 힌트**를 받으려면 이 PC에
[Ollama](https://ollama.com) 가 켜져 있어야 합니다. 이것만은 폴더 안에 넣을 수 없습니다
(모델 파일이 수 GB라 게임과 함께 두기 어렵습니다).

**Ollama가 없어도 스무고개는 그대로 할 수 있습니다.** 그때는 문장 힌트 대신
글자 수·초성·첫 글자 힌트가 열리고, 화면이 그 사실을 알려 줍니다.

## 개발자용 메모

- `.gitignore` 는 `tools/` 와 `node_modules/` 를 저장소에서 빼 둡니다(용량 때문입니다).
  그래서 **폴더를 통째로 복사하면 그대로 돌아가지만, `git clone` 으로 받으면** 그 둘이 없습니다.
  그때는 `서버 켜기.bat` 이 안내하는 대로 Node.js를 `tools/node/` 에 넣고,
  스크립트가 자동으로 `npm install` 을 돌립니다(이 과정에만 인터넷이 필요합니다).
- 작업 기록은 `docs/작업기록/작업기록.md` 에 한 건씩 쌓입니다.
