# 작업 기록 폴더

Claude Code로 작업할 때마다 **입력한 프롬프트**와 **AI가 실제로 한 작업**을 남겨 두는 곳입니다.

## 파일 구성

| 파일 | 내용 | 누가 채우나 |
|---|---|---|
| `작업기록.md` | 요청 + 작업 내용 + 검증 결과를 한 건씩 정리한 **메인 기록** | AI가 작업을 마칠 때마다 추가 |
| `프롬프트-원문.md` | 입력한 프롬프트 원문 (시간·세션 포함) | **훅이 자동 기록** |
| `_프롬프트기록.py` | 위 자동 기록을 수행하는 스크립트 | 건드릴 필요 없음 |

## 자동 기록은 어떻게 동작하나요?

`.claude/settings.json`에 등록된 `UserPromptSubmit` 훅이, 프롬프트를 입력할 때마다
`_프롬프트기록.py`를 실행해 `프롬프트-원문.md` 맨 아래에 내용을 덧붙입니다.

```json
{
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [ { "type": "command", "command": "python \"${CLAUDE_PROJECT_DIR:-.}/docs/작업기록/_프롬프트기록.py\" ..." } ] }
    ]
  }
}
```

- 설정을 바꾼 직후에는 `/hooks` 를 한 번 열거나 Claude Code를 다시 실행해야 훅이 적용됩니다.
- 자동 기록을 끄고 싶으면 `.claude/settings.json`의 `UserPromptSubmit` 항목을 지우면 됩니다.
- 기록이 실패해도 작업은 그대로 진행됩니다 (오류를 무시하도록 되어 있습니다).

## 작업 내용은 어떻게 쌓이나요?

프로젝트 루트의 `CLAUDE.md`에 "작업을 마치면 `작업기록.md`에 항목을 추가한다"는 규칙이 적혀 있어,
Claude Code가 매 작업 끝에 스스로 기록을 추가합니다.
빠뜨렸다면 **"작업기록 남겨줘"** 라고 말하면 됩니다.

## 직접 적을 때 쓰는 형식

```markdown
## 006 · 2026-09-01 · 한 줄 요약

**요청한 내용**

> 입력했던 프롬프트

**AI가 한 일**

1. 무엇을 어떻게 바꿨는지
2. 왜 그렇게 했는지

**검증** — 어떻게 확인했는지
```

맨 위의 표에도 같은 번호로 한 줄을 추가해 주세요.
