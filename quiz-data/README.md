# 문제 파일 (모드 3)

게임의 **모드 3 · 산업재산권 문제**가 여기 있는 파일을 읽어 문제를 냅니다.
지금은 `산업재산권_문제.txt` 하나를 씁니다.

## 형식

**두 줄이 한 쌍**입니다. 빈 줄은 몇 개가 있든 상관없습니다.

```
문제: 자연법칙을 이용한 기술적 사상의 창작으로서 고도한 것(발명)을 무엇이라고 하나요?
답: 특허
```

- `답` 뒤의 콜론 앞뒤 공백은 있어도 되고 없어도 됩니다 (`답 : 특허` 도 됩니다).
- 정답이 여러 개면 **쉼표로** 나눕니다.

```
문제: 지식재산권을 구성하는 3대 기본 영역은 무엇인가요? (정답 3개)
답: 산업재산권, 저작권, 신지식재산권
```

## 알아 둘 점

- **정답은 블록으로 만들 수 있어야 합니다.** 게임이 정답 글자를 보드에 깔아 주고,
  플레이어가 그 글자를 눌러 정답을 만듭니다. 정답 안의 공백은 게임이 지우고 읽습니다
  (`신 지식` → `신지식`). 문장으로 된 긴 정답은 10초 안에 만들 수 없으니 **낱말**로 적어주세요.
- **정답이 여러 개인 문제는 그중 하나만 만들어도 정답**으로 칩니다.
  10초 안에 여러 낱말을 잇달아 만드는 것이 사실상 불가능하기 때문입니다.
  결과 화면에서는 정답을 전부 보여 줍니다.
- 파일에 적힌 **순서 그대로** 전부 냅니다. 문제를 추가하면 그만큼 라운드가 늘어납니다.
- 저장은 **UTF-8** 로 합니다. 줄바꿈은 Windows(CRLF)든 Linux(LF)든 상관없습니다.

## 문제를 늘리는 두 가지 방법

### 1) 게임 안에서 (권장 — 파일을 건드리지 않아도 됩니다)

⚙️ **게임 설정 → 📜 모드 3 → 문제 파일 추가** 에서:

1. **[문제 파일 받기]** — 지금 내는 문제 전부를 이 형식의 `.txt` 로 내려받습니다.
2. 내려받은 파일 **아래에 새 문제를 덧붙여** 저장합니다 (메모장으로 열어 고쳐도 됩니다).
3. **[파일 선택]** 으로 그 파일을 다시 올립니다.

**이미 있는 문제는 건너뜁니다.** 그래서 전체 파일을 통째로 다시 올려도 같은 문제가 두 번
나오지 않고, 새로 적은 것만 늘어납니다. 추가한 문제는 그 브라우저에 저장되며,
설정 화면의 목록에서 하나씩 지울 수 있습니다.

메모장이 UTF-8 로 저장하며 붙이는 BOM 도 게임이 알아서 걸러 읽습니다.

### 2) 이 파일을 직접 고쳐서

`산업재산권_문제.txt` 에 같은 형식으로 덧붙이면 됩니다. 이렇게 고친 문제는 **모두에게** 나갑니다
(위 1번은 그 브라우저에만 남습니다). 서버로 서비스 중이라면 파일을 올린 뒤 다시 배포해야 합니다.

## 시간과 블록 개수

⚙️ **게임 설정 → 📜 모드 3** 에서 **한 문제 시간(5~120초)** 과 **블록 개수(4~36개)** 를 정합니다.
이 값은 **모드 1(제시어 맞추기)의 설정과 별개**입니다 — 한쪽을 바꿔도 다른 쪽은 그대로입니다.

정답 글자가 설정한 블록 개수에 다 들어가지 못하면, 게임이 그 판만 블록을 자동으로 늘립니다.
(정답을 만들 수 없는 판이 나오지 않게 하기 위해서입니다.)

## 다른 문제 파일을 쓰려면

파일 이름이 게임 안에 `EXAM_FILE` 상수로 박혀 있습니다
(`word_connection_game.html` 에서 `const EXAM_FILE` 을 찾으면 됩니다).
다른 파일을 쓰려면 그 값을 바꾸세요.
