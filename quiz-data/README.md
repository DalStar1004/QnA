# 문제 파일 (모드 3)

게임의 **모드 3 · 산업재산권 문제**가 여기 있는 파일을 읽어 문제를 냅니다.
지금은 `산업재산권_문제.txt` 하나를 씁니다.

## 형식

**두 줄이 한 쌍**입니다. 빈 줄은 몇 개가 있든 상관없습니다.

```
문제: 자연법칙을 이용한 기술적 사상의 창작으로서 고도한 것(발명)을 무엇이라고 하나요?
답: 특허
```

- `답` 뒤의 콜론 앞뒤 공백은 있어도 되고 없어도 됩니다 (`답 : 특허` 도 됩니다).
- 정답이 여러 개면 **쉼표로** 나눕니다.

```
문제: 지식재산권을 구성하는 3대 기본 영역은 무엇인가요? (정답 3개)
답: 산업재산권, 저작권, 신지식재산권
```

## 알아 둘 점

- **정답은 블록으로 만들 수 있어야 합니다.** 게임이 정답 글자를 보드에 깔아 주고,
  플레이어가 그 글자를 눌러 정답을 만듭니다. 정답 안의 공백은 게임이 지우고 읽습니다
  (`신 지식` → `신지식`). 문장으로 된 긴 정답은 10초 안에 만들 수 없으니 **낱말**로 적어주세요.
- **정답이 여러 개인 문제는 그중 하나만 만들어도 정답**으로 칩니다.
  10초 안에 여러 낱말을 잇달아 만드는 것이 사실상 불가능하기 때문입니다.
  결과 화면에서는 정답을 전부 보여 줍니다.
- 파일에 적힌 **순서 그대로** 전부 냅니다. 문제를 추가하면 그만큼 라운드가 늘어납니다.
- 저장은 **UTF-8** 로 합니다. 줄바꿈은 Windows(CRLF)든 Linux(LF)든 상관없습니다.

## 새 문제 파일을 추가하려면

지금은 파일 이름이 게임 안에 `EXAM_FILE` 상수로 박혀 있습니다
(`word_connection_game.html` 에서 `const EXAM_FILE` 을 찾으면 됩니다).
다른 파일을 쓰려면 그 값을 바꾸세요.
