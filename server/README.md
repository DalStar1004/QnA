# 단어 연결 게임 — 실시간 멀티플레이 서버

`word_connection_game.html`(싱글플레이)을 여러 사람이 같은 방에서 실시간으로 경쟁할 수 있게 확장한 서버입니다.

- 관련 문서: [Plan](../docs/01-plan/features/word-connection-multiplayer.plan.md) · [Design](../docs/02-design/features/word-connection-multiplayer.design.md)

## 실행하기

### 가장 쉬운 방법 — `서버 켜기.bat` 더블클릭 (권장)

프로젝트 폴더(`QnA/`)에 있는 **`서버 켜기.bat`** 을 더블클릭하면 끝입니다.
검은 창이 열리면서 서버가 뜨고, 잠시 뒤 브라우저에 게임 화면이 자동으로 열립니다.

이 배치 파일은 다음을 알아서 처리합니다.

1. `tools/node`(프로젝트에 같이 둔 포터블 Node.js)를 찾아 실행에 사용합니다.
   PC에 Node.js가 따로 설치돼 있다면 그것을 씁니다.
2. 처음 실행이라 `node_modules`가 없으면 `npm install`을 먼저 돌립니다.
3. 서버를 켠 뒤, **이 PC 주소와 같은 인터넷의 다른 PC가 쓸 주소**를 화면에 적어 줍니다.

같은 네트워크의 다른 PC는 그 창에 표시된 `http://192.168.x.x:3000` 형태의 주소로 접속하면 됩니다.
(처음 켤 때 Windows 방화벽 창이 뜨면 **[액세스 허용]** 을 눌러야 다른 PC에서 들어올 수 있습니다.)

> `tools/node` 는 **저장소에 함께 들어 있습니다.** `git clone` 으로 받아도 그대로 있으므로
> Node.js를 따로 설치할 필요가 없습니다.
>
> 혹시 그 폴더가 지워졌다면 <https://nodejs.org/ko/download> 에서 **Windows 64-bit ZIP**을 받아
> 압축을 풀고 폴더 이름을 `node`로 바꿔 `QnA/tools/node/node.exe` 가 되도록 넣으면 됩니다.
> 설치 프로그램(.msi)으로 Node.js를 정식 설치해도 똑같이 동작합니다.

### Docker

```bash
cd server
docker compose up --build
```

기동 후 브라우저에서 <http://localhost:3000> 으로 접속합니다.
같은 네트워크의 다른 PC에서는 서버 PC의 IP로 접속하세요 (예: `http://192.168.0.10:3000`).

호스트 포트를 바꾸려면 `docker-compose.yml`의 `ports`를 `"8080:3000"` 처럼 수정하면 됩니다.

### Docker 없이 직접 실행

```bash
cd server
npm install
npm start
```

## 게임 방법

> ⚠️ 이 화면은 **반드시 서버 주소로** 열어야 합니다 (`http://localhost:3000`).
> `public/index.html` 파일을 직접 더블클릭하면 `socket.io` 클라이언트를 못 불러와
> [방 만들기]·[참가하기] 를 포함한 모든 버튼이 동작하지 않습니다.
> 그렇게 연 경우에는 화면에 안내가 뜹니다.

1. 닉네임을 입력하고 **방 만들기** → 4자리 방 코드가 나옵니다.
2. 친구들은 같은 화면에서 닉네임 + 방 코드를 입력해 **참가하기**.
3. 방장이 대기실에서 **게임 종류**를 고릅니다 — 🧩 제시어 맞추기 / 🤖 AI 스무고개.
   카테고리는 두 종류 모두 혼자 하기와 같은 **20종**을 씁니다.
4. 설정을 마치고 **게임 시작** (최소 2명).
5. 전원에게 동일한 최종 순위표가 표시됩니다. 방장이 **다시하기**로 재시작할 수 있습니다.
6. 도중에 그만두려면 화면 위쪽 **[🚪 게임에서 나가기]** 를 누릅니다. 방에서 빠져나오고,
   시작 화면에서 들어왔다면 그 화면(혼자/멀티 고르기)으로 돌아갑니다.
   방장이 나가면 남은 사람 중 한 명에게 방장이 넘어갑니다.

### 🧩 제시어 맞추기

방장이 블록 개수(4~36)와 게임 시간(30 · 60 · 90 · 120 · 180 · 300초)을 정합니다.
모두 **같은 보드**를 보며 블록을 드래그해 단어를 만듭니다.
**먼저 맞힌 사람만** 1점을 얻고 곧바로 다음 라운드로 넘어가며, 정한 시간이 지나면 끝납니다.

이번 게임에서 **이미 맞힌 낱말을 다시 내면** `이미 찾은 단어예요!` 라고 알려 주고 다시 고르게 합니다.
점수도 오르지 않고 판도 끝나지 않습니다(혼자 하기와 같은 규칙). 이미 맞힌 낱말은
다음 판의 목표 단어에서도 빠집니다.

### 🤖 AI 스무고개

혼자 하기의 모드 2(AI 스무고개)와 **같은 방식·같은 화면**입니다.

방장이 문제 수(3 · 5 · 7 · 10)와 블록 개수를 정합니다. 라운드마다 서버가 카테고리에서 낱말 하나를 고르고,
그 글자가 들어간 보드를 깔아 준 뒤 **10초마다 힌트를 하나씩** 방 전체에 같은 순서로 열어 줍니다.
정답은 입력창에 적는 것이 아니라 **보드에서 블록을 이어** 만듭니다(제시어 맞추기와 같은 조작).
보드 옆에는 힌트가 하나씩 쌓이는 패널이 붙습니다.

점수도 혼자 하기와 같습니다 — **힌트를 적게 보고 맞힐수록 높은 점수**입니다.
힌트 1개만 보고 맞히면 6점, 6개를 다 보고 맞히면 1점이며, 먼저 맞힌 한 명만 얻습니다.
마지막 힌트 이후 20초가 지나도 아무도 못 맞히면 정답을 공개하고 다음 문제로 넘어갑니다.

힌트를 만드는 **로컬 LLM(Ollama)은 서버가 호출합니다.** 각자의 브라우저가 부르지 않는 이유는 두 가지입니다.
정답이 서버 밖으로 나가지 않아야 하고, 모두가 **같은 힌트**를 봐야 공정하기 때문입니다.

```bash
# 기본값 — 서버와 같은 PC의 Ollama 를 씁니다
OLLAMA_URL=http://127.0.0.1:11434  OLLAMA_MODEL=qwen2.5:7b
```

#### AI 연결은 자동입니다

사람이 [연결] 같은 것을 누를 필요가 없습니다. 서버가 세 지점에서 알아서 붙습니다.

1. **서버를 켤 때** — 연결을 확인하고 모델을 메모리에 올려 둡니다.
   이 예열이 없으면 첫 문제까지 2~3분을 기다립니다(실측: 콜드 상태 167초).
2. **방장이 대기실에서 스무고개를 고를 때** — 사람들을 모으는 동안 연결을 끝내 둡니다.
3. **문제를 만들 때** — 그때까지도 연결이 없으면 한 번 더 붙어 봅니다.
   중간에 Ollama 가 꺼졌다 켜져도 다음 요청에서 다시 붙습니다.

설정한 모델이 설치돼 있지 않으면 **설치된 모델 중에서 자동으로 골라** 씁니다
(qwen2.5 → qwen2 → llama3.2 → … 순). 서버 로그와 게임 화면에 무엇으로 바꿨는지 표시됩니다.

**AI 가 아예 없어도 게임은 진행됩니다.** 그때는 문장 힌트 없이 확정 힌트
(글자 수 · 초성 · 첫 글자)만 열리고, 대기실과 게임 화면에 그 사실을 알려 줍니다.

### 🖼 게임 배경

화면 위쪽 **[🖼 게임 배경]** 을 눌러 기본 배경 + 배경1~4 중에서 고릅니다(혼자 하기와 같은 그림).
로비·대기실·게임 중 언제든 바꿀 수 있습니다.

배경은 **보는 사람마다 따로** 고릅니다. 방 전체에 강요되지 않고, 서버를 거치지도 않습니다.
고른 값은 그 브라우저에만 기억해 두므로 다음에 들어와도 그대로 열립니다.
그림 파일은 `public/assets/bg1~4.png`(원본)와 `thumb-bg1~4.png`(미리보기)에 있습니다.

### 카테고리 — 혼자 하기와 같은 20종

카테고리와 단어 목록은 **서버의 `src/domain/dictionary.js` 가 원본**입니다.
방을 만들거나 참가할 때 서버가 목록을 함께 내려주므로, 사전에 카테고리를 추가하면
클라이언트를 고치지 않아도 선택칸에 바로 나타납니다.
다만 혼자 하기 모드(`word_connection_game.html`)와는 여전히 별개의 사본이므로,
한쪽 사전을 늘리면 다른 쪽도 함께 맞춰 주세요.

### 정답 규칙 (제시어 맞추기) — 글자 수 제한 없음

목표 글자 수 설정은 없습니다. 보드에 깔린 글자로 만들 수 있고 **이번 판 카테고리의 단어**이기만 하면
2글자든 5글자든 모두 정답입니다(혼자 하기 모드와 같은 규칙). 서버는 매 라운드 그 카테고리에서
길이가 서로 다를 수도 있는 단어 2개를 보드에 심어 두는데, 이는 "적어도 두 개는 반드시 만들 수 있다"를
보장하기 위한 것일 뿐 정답의 전부가 아닙니다.

## 구조 (클린 아키텍처)

```
src/
├── domain/          순수 게임 규칙 — Room, Player, Round, QuizRound, dictionary, quizContent (I/O 없음)
├── application/     유스케이스 — RoomService, RoundService, QuizService (Port에만 의존)
├── infrastructure/  Port 구현 — InMemoryRoomRepository, SocketIOBroadcaster,
│                    roomCodeGenerator, OllamaHintGenerator
├── presentation/    socketHandlers — 소켓 이벤트 ↔ 유스케이스 변환
└── server.js        합성 루트 — 의존성 주입 + Express/Socket.IO 부트스트랩
public/index.html    멀티플레이 클라이언트 (로비 / 대기실 / 게임 / 게임오버)
```

정답 판정은 **전적으로 서버 권한**입니다. 정답 단어는 클라이언트로 전송되지 않으며,
동시에 여러 명이 같은 답을 제출해도 `Round.solved` 플래그 덕분에 정확히 한 명만 득점합니다.

## 인터넷 없이도 됩니다

서버를 굴리는 데 필요한 것은 모두 이 저장소 폴더 안에 있습니다.

- **Node.js** — `../tools/node/` (PC에 설치하지 않아도 됩니다)
- **라이브러리** — `node_modules/` (express, socket.io)
- **socket.io 클라이언트** — 서버가 `/socket.io/socket.io.js` 로 직접 내려줍니다 (CDN 아님)
- **글꼴** — `public/assets/fonts/` (예전에는 구글 폰트를 인터넷에서 받아 썼습니다)
- **그림** — `public/assets/`

바깥이 필요한 것은 **AI 스무고개의 문장 힌트를 만드는 Ollama** 하나뿐이고,
그것도 없으면 글자 수·초성 힌트로 게임이 그대로 진행됩니다.

## 알려진 제약 (의도된 범위 밖)

- 상태를 메모리에만 보관하므로 **서버를 재시작하면 모든 방이 사라집니다**.
- 로그인/회원가입, 전적 영구 저장, 재접속 복구, 자동 매칭메이킹은 지원하지 않습니다.
- 모바일 터치 드래그는 지원하지 않습니다 (마우스 전용).
- 부정행위 방지(anti-cheat) 로직은 없습니다 — 지인 간 캐주얼 플레이를 전제로 합니다.
